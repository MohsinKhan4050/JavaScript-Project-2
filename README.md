# Multiplication Practice App

A simple and interactive web application that helps users practice multiplication questions and improve their math skills.

This project was built using **HTML, CSS, and JavaScript** and generates random multiplication questions with a live scoring system.

---

## Features

• Random multiplication questions  
• Live score tracking  
• Prevents negative score  
• Clean and simple UI  
• Instant new question generation after each answer  

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## How It Works

1. The app generates two random numbers.
2. The user enters the multiplication result.
3. If the answer is correct:
   - Score increases by **1**
4. If the answer is wrong:
   - Score decreases by **1** (but never below 0)
5. A new question appears instantly.
